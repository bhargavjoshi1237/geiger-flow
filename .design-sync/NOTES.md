# Design Sync Notes — Geiger Flow

## Setup facts

- **Shape**: package (no Storybook)
- **Source**: `components/ui/` (38 shadcn/ui primitives) + `components/internal/shared/` (5 custom components)
- **CSS**: Tailwind v4 — must compile before running the converter: `npx tailwindcss -i ./app/globals.css -o ./app/compiled-styles.css`
- **No dist, no TypeScript**: Synth-entry mode from JSX source. Props contracts are inferred, not typed.
- **Package manager**: npm (`package-lock.json`). Use `npm ci` on fresh installs.
- **Node version**: not pinned — use current system Node.

## Known quirks

- `app/compiled-styles.css` is generated by Tailwind CLI — it is `.gitignore`d. Re-sync must run `buildCmd` before the converter.
- `globals.css` imports `@import "shadcn/tailwind.css"` — this must resolve from `node_modules/shadcn/tailwind.css`; ensure deps are installed.
- Geist Sans/Mono fonts are loaded by Next.js at runtime via `next/font`. They are NOT shipped with the DS bundle. Expect `[FONT_MISSING]`; set `runtimeFontPrefixes: ["Geist"]` if it fires.
- `screen_wrappers.jsx` exports two components: `MainScreenWrapper` and `SecondaryScreenWrapper`. Both are pinned in `componentSrcMap`.
- `deadlines.jsx` exports `DeadlinesSection` (not `Deadlines`).

## Re-sync risks

- Tailwind CSS version bump may change compiled output — verify render check after upgrading `tailwindcss`.
- `shadcn/tailwind.css` may change on `shadcn` package upgrades.
- Internal shared components (`DeadlinesSection`, `MainScreenWrapper`, `SecondaryScreenWrapper`, `SegmentedTabs`, `IconButtonCard`) have strong internal dependencies (Supabase, context providers) — previews may need `cfg.overrides.<Name>.skip` if they throw.
